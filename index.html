Quick Start

Contoh Penggunaan

Contoh request menggunakan JavaScript Fetch.

JavaScript · Fetch API 
const API_BASE = 'https://domain-kamu.com';

async function getAnime() {
  try {
    const response = await fetch(
      `${API_BASE}/api/anime`
    );

    if (!response.ok) {
      throw new Error('Request gagal');
    }

    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

getAnime();

Catatan: ganti domain dan path contoh dengan alamat server serta endpoint yang benar-benar disediakan API kamu.
